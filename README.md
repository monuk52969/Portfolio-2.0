# 🌐 Monu Kumar | Web Developer Portfolio

### Built with React, TailwindCSS, and GSAP

This is a fully animated, modern frontend portfolio showcasing my web development projects, skills, and interactive UI designs. It’s designed to highlight real-world frontend capabilities in a clean and responsive way.

---

## 🚀 Tech Stack

| Technology       | Description                             |
| ---------------- | --------------------------------------- |
| **React (Vite)** | Fast dev server and production bundling |
| **Tailwind CSS** | Utility-first styling for components    |
| **GSAP**         | Scroll-based animation and motion logic |
| **Framer Motion**| Smooth component and hover animations   |

---

## 📁 Features

- 🎯 Hero Section with large typography & scroll animations
- 🧩 Animated Navbar with smooth scroll interactions
- 💼 Service Summary & Services sections with modern card animations
- ✍️ About section with clip-path image reveal and animated text
- 🖼️ Works section showcasing projects with hover effects
- 📬 Contact section with animated form and call-to-action
- 📱 Fully responsive and works on all devices
